# Recipe Book

***Статус: В разработке 🚀***

**Это удобное хранилище рецептов, где вы можете:**

+ 📁 *Сохранять любимые рецепты в одном месте*
+ 👨👦 *Делиться ими с семьей и друзьями (подключайте пользователей к своему "семейному" аккаунту)*
+ 🛒 *Формировать списки покупок на основе выбранных рецептов*

🔥 **Возможности:**
+ ✅ *Общее пространство для семьи/друзей*
+ ✅ *Быстрый поиск по названию блюда или напитка*
+ ✅ *Список покупок для похода в магазин*
